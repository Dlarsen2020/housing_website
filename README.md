Housing Locator Website

A responsive, student-focused housing search tool built to help BYU–Idaho students quickly find apartment complexes based on their preferences.

📌 Overview

The Housing Locator allows users to browse and filter student housing using a simple and intuitive interface. Students can narrow down apartments by price, amenities, and housing type, making it easier to find a living situation that fits their needs.

✨ Features

Search Bar: Enter a department or keyword to begin your housing search.

Filtering Criteria:

Private rooms

In-unit laundry

Parking availability

Male/Female housing

Price range

Apartment Results: Displays image previews of apartment complexes.

Responsive Layout: Clean and accessible design for desktop and mobile.

🛠️ Technologies Used

HTML5 for structure

CSS3 for styling and layout

🎯 Project Goals

Create a simple housing-search interface for students

Build clean, readable, and scalable front-end code

Practice real-world UI layout techniques

Prepare the project for future expansion (dynamic filters, API data, etc.)
